# 12345-EventPulse

EventPulse is a RESTful backend API for an Event Management Platform. It provides authentication and authorization, event management, categories, event registrations, announcements, real-time communication with Socket.io, validation, centralized error handling, automated testing, and cloud deployment.

## 🚀 Live Deployment

**Health Check:** https://12345-event-pulse-aupy.vercel.app/health

**Swagger API Documentation:** https://12345-event-pulse-aupy.vercel.app/api-docs

## 🛠️ Tech Stack

- Node.js

- JWT Authentication
- bcryptjs
- Socket.io
- express-validator
- Swagger / OpenAPI
- Jest
